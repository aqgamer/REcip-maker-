# ⚡ Cyberpunk Neon Card Component

A modern, high-performance UI card component crafted with zero external dependencies.

### Features
- **Frosted Glassmorphism:** CSS backdrop blur overlay for modern dark themes.
- **Neon Glow Hover Effect:** Dynamic multi-color ambient lighting built with pure CSS.
- **Micro-Interactions:** Hardware-accelerated hover scaling and arrow transitions.
- **Zero JS Required:** Fully responsive styling using modern CSS variables.

### Tech Stack
- HTML5
- CSS3 (Custom Properties, Flexbox, Pseudo-elements)
